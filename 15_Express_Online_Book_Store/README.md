# 15 Express Online Book Store

Online Book Store REST API using Express. Requirements: Node.js 18+. In this folder run npm install, then npm start. Server: http://localhost:3000. Endpoints include GET /books, GET /books/:id, POST /books, PUT /books/:id, DELETE /books/:id, GET/POST /cart and GET/POST /orders. Test in a second terminal with npm test. Data is stored in memory and resets when the server restarts.
